# 🌐 Aniket Rathod – Developer Portfolio

[![Live Website](https://img.shields.io/badge/Live-Website-blue)](https://aniketrathod.com) 

[![GitHub Repo](https://img.shields.io/badge/GitHub-Repository-black)](https://github.com/aniirathod/Aniket_Rathod)


A modern, animation-rich, performance-optimized developer portfolio built to highlight my work, skills, and design style. Focused on fast load times, smooth interactions, and a premium visual experience.

---

## 🚀 Tech Stack

### **Frontend**
- **React.js** – Component architecture & efficient rendering  
- **Tailwind CSS** – Utility-first styling with clean, responsive UI  
- **Framer Motion** – Smooth animations, transitions & micro-interactions  
- **Locomotive Scroll (Beta)** – Smooth scroll + parallax + scroll-based motion  

### **Integrations**
- **Web3Forms** – Backend-free contact form with validation and email delivery  

---

## 📄 Pages Overview

### **🏠 Home Page**
- Smooth-scroll landing with locomotive effects
